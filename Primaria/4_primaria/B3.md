# Planificación de Computación — 4.º primaria — B3 — 2027

## Bimestre III — Diseño algoritmos con decisiones y pruebas

**Fechas:** 31 de mayo–30 de julio. COE/autoevaluación 7–11 de junio; parcial 16–22 de junio; semana de Medio Año 28 de junio–2 de julio; heteroevaluaciones 26–30 de julio.  
**Períodos potenciales:** 18; reubicar sesiones si la semana de Medio Año no es lectiva.  
**Pregunta guía:** ¿Cómo puede una secuencia elegir entre caminos y cómo sé que funciona en más de un caso?  
**Producto:** solución documentada a un reto lógico con diagrama, condición, repetición y pruebas de casos.

### Propósito y articulación

El estudiante representa procedimientos con diagramas de flujo sencillos; compara secuencia, repetición y condición; predice los resultados; y prueba casos distintos para detectar errores. El trabajo se realiza en tarjetas, papel, Code.org u otra herramienta visual preparada; no se exige programación textual.

Matemáticas del CNB de 4.º vincula signos, figuras, relaciones y organización de procesos para resolver problemas. Comunicación y Lenguaje aporta explicación de procedimientos; Ciencias Naturales y Tecnología, observación, prueba y solución de problemas. CSTA y Computing de Inglaterra complementan con algoritmos, secuencia, selección, repetición, eventos y depuración.

### Ejercicios de cuaderno — B3

1. Divide una tarea en tres subproblemas.
2. Ordena pasos y señala el resultado.
3. Dibuja un diagrama con inicio, acciones y final.
4. Reemplaza una serie repetida por un ciclo.
5. Completa una condición con dos caminos posibles.
6. Sigue ambos resultados de una condición.
7. Encuentra la primera flecha o decisión incorrecta.
8. Completa una tabla de entrada, camino y salida.
9. Prueba el mismo algoritmo con una segunda entrada.
10. Corrige una condición después de comparar resultados.
11. Compara una secuencia expandida con una repetición visual.
12. Diseña un diagrama para un problema cotidiano y anota casos de prueba.

### Hojas imprimibles — B3

#### Hoja 1 — Ordeno y diagramo

**Nombre:** _______________________________  **Fecha:** ______________

Ordena: inicio, revisar materiales, realizar actividad, guardar materiales, fin. Dibuja las flechas.

**Clave:** inicio → revisar → realizar → guardar → fin.

#### Hoja 2 — Una decisión, dos caminos

**Nombre:** _______________________________  **Fecha:** ______________

Regla: si el semáforo está verde, cruzo con adulto; si está rojo, espero. Completa:

| Entrada | Acción |
|---|---|
| Verde | |
| Rojo | |

**Clave:** verde = cruzo con adulto; rojo = espero.

#### Hoja 3 — Represento repetición

**Nombre:** _______________________________  **Fecha:** ______________

Ruta: ↑ ↑ ↑ → →. Completa: repite ↑ ___ veces y luego → ___ veces.

**Clave:** 3 y 2.

#### Hoja 4 — Trazo los casos

**Nombre:** _______________________________  **Fecha:** ______________

Regla: si un libro está prestado, lo reservo; si no, lo tomo. Completa:

| Libro disponible | Camino | Resultado |
|---|---|---|
| Sí | | |
| No | | |

**Clave:** sí → tomarlo; no → reservarlo. Aceptar respuestas coherentes con la regla si el estudiante formula la condición al revés y mantiene consistencia.

#### Hoja 5 — Depuro el diagrama

**Nombre:** _______________________________  **Fecha:** ______________

Algoritmo: Inicio → preguntar “¿está seco?” → si sí, guardar; si no, guardar.  
Rodea el problema y propone un camino distinto para “no”.

**Clave:** ambos caminos dan el mismo resultado; si no está seco, dejar secar o consultar antes de guardar.

#### Hoja 6 — Diseño un reto y lo pruebo

**Nombre:** _______________________________  **Fecha:** ______________

Problema: _______________________________  
Entrada/caso 1: __________ Resultado esperado: __________  
Entrada/caso 2: __________ Resultado esperado: __________  
Dibuja secuencia, condición o repetición y una mejora después de probar.

**Clave:** abierta; comprobar que el diagrama coincide con ambos casos.

### Tareas sin computadora — B3

1. **Un proceso repetido (2 puntos):** dibuja una actividad con un paso que se repite.
2. **Una condición (2 puntos):** inventa una regla “si… entonces…” con dos resultados.
3. **Prueba una solución (1 punto):** cambia una entrada de un algoritmo y señala si cambia el resultado.

### Parcial — 20 puntos

1. Ordenar acciones y dibujar inicio/fin (4).
2. Representar una repetición de tres pasos (4).
3. Seguir dos casos de una condición simple (4).
4. Localizar un error en un diagrama (4).
5. Completar dos filas de prueba y comparar resultado esperado/observado (4).

**Clave:** aceptar representaciones gráficas consistentes; cada camino debe corresponder a su condición; identificar el primer punto donde la solución deja de seguir la regla; evaluar el procedimiento de prueba, no la caligrafía.

### Producto integrador — 15 puntos

**Solución documentada a un reto lógico.** Diagrama de flujo con secuencia, condición y repetición visual, más dos casos de prueba y una revisión.

| Criterio | 5 puntos | 3–4 puntos | 1–2 puntos | 0 puntos |
|---|---|---|---|---|
| Algoritmo | Representa los pasos y caminos que resuelven el reto. | Resuelve con una corrección menor. | Completa una parte con apoyo. | Aún no representa una solución. |
| Repetición/condición | Usa ambas con relación clara al problema. | Una está clara y la otra necesita ajuste. | Reconoce una con guía. | Aún no las relaciona. |
| Pruebas y depuración | Registra dos casos y usa resultados para mejorar. | Prueba ambos con una explicación menor. | Prueba un caso con apoyo. | Aún no prueba la solución. |

### Heteroevaluación — 20 puntos

**Parte visual — 10:** interpretar secuencia (2); reconocer ciclo (2); seguir condición con dos entradas (3); identificar error lógico (3).

**Parte práctica — 10:** trazar dos casos (4); corregir un paso (3); explicar por qué el ajuste resuelve el caso (2); cuidar equipo y turnos (1).

### Teoría y cápsula histórica

**Teoría:** algoritmo, condición, prueba y depuración. **Historia:** Babbage planeó una máquina con operaciones controladas por instrucciones; conecta la idea con nuestros diagramas y bloques. [CHM: motor de Babbage](https://www.computerhistory.org/babbage/history/).

*Dedicarle 5–7 minutos dentro de una sesión: explicar la idea, conectarla con una práctica del bimestre y cerrar con una pregunta. No agregar una sesión ni convertir las fechas históricas en memorización.*
