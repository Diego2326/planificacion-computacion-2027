# Computación — 1.º primaria — B4 — 2027

## Bimestre IV — Creo y guardo una composición digital

**Fechas:** 2 ago–15 oct · COE 23–27 ago · parcial/avance 30 ago–3 sep · heteroevaluación oficial 4–8 oct y segunda parte interna 11–15 oct. **Hasta 22 períodos potenciales**; algunas actividades institucionales pueden alterar sesiones.  
**Pregunta guía:** ¿Cómo organizo figuras e imágenes en una aplicación y conservo mi trabajo?  
**Meta de Computación:** usar herramientas de una aplicación local para componer, seleccionar, mover, corregir y guardar una imagen de varios pasos. El tema es el cuidado del equipo; la evaluación se centra en operaciones digitales, no en producir un relato escrito.

### Secuencia de hasta 22 períodos

| Períodos | Enfoque y práctica |
|---|---|
| 1–2 | Repaso de mouse, selección, formas y reglas de laboratorio. |
| 3–4 | Abrir una plantilla local; reconocer lienzo, barra de herramientas y paleta. |
| 5–6 | Crear formas para representar tres pasos de cuidado del computador. |
| 7–8 | Seleccionar, mover y cambiar tamaño de una forma; usar deshacer. COE/autoevaluación en la ventana institucional. |
| 9–10 | Parcial de avance: demostrar herramienta, orden y corrección en una plantilla. |
| 11–12 | Añadir color y detalle con relleno/contorno; mantener el dibujo visible. |
| 13–14 | Crear tres recuadros o escenas en orden; usar iconos y flechas, texto opcional de una palabra. |
| 15–16 | Guardar con el nombre indicado; localizar el archivo y abrirlo de nuevo. |
| 17–18 | Revisar imagen, orden, legibilidad y cuidado de datos. |
| 19–20 | Ensayar mostrar la composición localmente y explicar una operación usada. |
| 21 | Heteroevaluación práctica: completar una modificación asignada. |
| 22 | Cerrar portafolio, recoger evidencias y autoevaluar una habilidad digital. |

### Cuaderno: 12 ejercicios

1. Etiquetar lienzo y herramientas. 2. Relacionar iconos con acciones. 3. Ordenar abrir plantilla/crear/guardar. 4. Dibujar una forma y una selección. 5. Indicar cómo mover una figura. 6. Mostrar un cambio de tamaño. 7. Comparar usar borrador y deshacer. 8. Diseñar iconos para cuidado del equipo. 9. Ordenar tres pasos con flechas. 10. Revisar tamaño y contraste de figuras. 11. Ubicar el archivo dentro de una carpeta. 12. Marcar qué datos no se deben incluir.

### Hojas imprimibles y claves

1. **Partes del editor:** lienzo = espacio de dibujo; herramienta = acción; paleta = color. 2. **Elijo la herramienta:** círculo para rueda, rectángulo para pantalla, línea para cable (aceptar alternativas justificadas). 3. **Muevo y cambio tamaño:** seleccionar primero y luego arrastrar; mantener proporción si aplica. 4. **Orden de pasos:** abrir plantilla, editar, guardar, abrir para comprobar. 5. **Corrijo una acción:** deshacer restaura el paso anterior; guardar conserva versión actual. 6. **Revisión segura:** sin nombres completos, teléfonos, direcciones ni contraseñas; compartir solo en clase.

### Prácticas digitales en PCs Windows

1. Explorar una plantilla local del editor. 2. Construir pictogramas con formas y color. 3. Reordenar y corregir figuras; guardar. 4. Volver a abrir y mostrar la composición. Alternativa sin PC: recortes de formas en tres paneles numerados.

### Tareas sin computadora

1. Diseñar tres iconos geométricos para cuidar un equipo (2 pts). 2. Ordenar con flechas tres acciones: sentarse, usar y apagar con permiso (2 pts). 3. Dibujar un nombre seguro para un archivo sin usar datos reales (1 pt).

### Evaluación

**Parcial de avance (20):** identificar lienzo/herramienta 4; elegir herramienta adecuada 4; ordenar operaciones 4; corregir un error visual 4; señalar una regla de privacidad 4.

**Producto (15): composición digital de tres pasos de cuidado del equipo.** Usa herramientas y formas (5); orden visual claro (5); archivo guardado y recuperable con apoyo (5). Puede añadir etiquetas dictadas o de una palabra.

**Heteroevaluación (20):** demostración individual en una plantilla preparada (10: seleccionar 2, crear/mover 3, corregir 2, guardar/recuperar 2, cuidado 1); preguntas visuales sobre herramienta, archivo y privacidad (10).

**Ponderación:** cuaderno 15 + hojas 15 + tareas 5 + prácticas 10 + parcial 20 + producto 15 + heteroevaluación 20 = **100 puntos**.

### Teoría y cápsula histórica

**Teoría:** archivo, carpeta, guardar y recuperar. **Historia:** las tarjetas perforadas dieron paso a cintas, disquetes y memorias flash; comparar cómo se transportaban los datos. [CHM: almacenamiento](https://www.computerhistory.org/storageengine/timeline/).
